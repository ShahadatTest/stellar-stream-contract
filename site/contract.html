Record

pub struct Watch {
    id: u64,             // monotonic, never reused
    target: Address,     // the watched contract
    owner: Address,      // only address allowed to remove it
    label: String,       // display name
    warn_ledgers: u32,   // warn window, 1 day .. 1 year
    added_ledger: u32,
    active: bool,
}

Events

WatchAdded { id, target, owner, warn_ledgers } and WatchRemoved { target, owner }. The full watchlist is reconstructible from these two events, which is the intended path for an indexer.

Self-preservation

Every read and write extends the registry's own instance and persistent TTLs (threshold 1 day, extension 30 days, clamped by the network). The watchdog must not be the first thing to expire — and deployments.json includes the registry itself, so its own deadline appears in every scan.

What it cannot do

  • Extend another contract's TTL. Soroban only allows the owning contract to do that.
  • Move or hold funds. It never calls a token.
  • Be upgraded. There is no admin and no upgrade entry point.
  • Vouch for a contract. Listing is a declaration, not an audit.
