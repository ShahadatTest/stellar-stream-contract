Roadmap

Sequenced by what unlocks the most value per unit of work. Every open item maps to a tracked issue.

v0.1 — shipped

  • Registry contract: permissionless watchlist, owner-only removal, monotonic ids, pagination, self-extending TTLs
  • TTL → wall-clock forecasting against Stellar's 5 second close time
  • Risk classification with a per-contract warn window
  • scan, verify, registry, doctor
  • Instance-key derivation for any contract id, with no cooperation from its authors
  • Testnet deployment, seeded watchlist, daily CI scan, this site

v0.2 — close the loop

  • sentinel restore — build and submit RestoreFootprint from the simulation preamble, dry-run by default
  • sentinel extend — call a contract's own extension hook with a ledger budget
  • maxEntryTtl-aware risk — never label a contract urgent when it is already at the network ceiling
  • Multi-RPC consensus — two endpoints, one disagreement report, so a lying RPC cannot hide a dead contract

v0.3 — make the watchlist trustworthy

  • Footprint indexer — derive persistent keys from WatchAdded/WatchRemoved plus RPC events
  • Bounty accounting — reimburse whoever pays to restore, once "this keeper really restored it" is verifiable
  • Ownership transfer — move a watch without allocating a new id

v0.4 — make it visible

  • Static status dashboard generated from scan --json
  • Webhook alerts on state transitions, deduplicated
  • Prometheus exporter

Non-goals

  • Extending a foreign contract's TTL from a shared contract — the protocol forbids it
  • Holding user funds
  • Generic multi-chain uptime monitoring — the forecast only means something because Soroban has a protocol-defined expiry
