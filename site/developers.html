Developers

The SDK is plain TypeScript with one dependency. Node runs it directly — no build step, no bundler, no generated client.

Local setup

git clone https://github.com/Streams-Hq/soroban-sentinel.git
cd soroban-sentinel
npm install

npm test          # node --test on the pure modules
npm run typecheck # tsc --noEmit
make test         # + cargo test for the contract (needs Rust)

Rust is only needed to build the contract. Everything under packages/ runs with Node 22.6+ alone.

Scan from code

import { openServer, resolveNetwork, scanTargets, renderJson } from "./packages/sdk/src/index.ts";

const cfg = resolveNetwork("testnet");
const server = openServer(cfg);

const result = await scanTargets(server, cfg, [
  {
    contractId: "CC4TQFW5GLQTOKWTDE7IJWPQFWJ4NWVMJGBFWB76PUP3T7CEOVVSQW6O",
    label: "Sentinel registry",
    warnLedgers: 518_400,
  },
]);

console.log(renderJson(result));
// result.summary -> { healthy, watch, urgent, critical, missing }

scanTargets batches keys 50 at a time through getLedgerEntries. Pass { now } in the options to make the forecast deterministic in a test.

Forecast without a network

import { projectTtl, classifyRisk, formatDuration } from "./packages/sdk/src/ttl.ts";

const projection = projectTtl({
  liveUntilLedger: 5_636_236,
  currentLedger: 5_515_284,
  warnLedgers: 518_400,
  now: Date.parse("2026-11-02T06:20:00Z"),
});

projection.risk            // "urgent"
projection.ledgersRemaining // 120952
formatDuration(projection.secondsRemaining) // "6d 23h"

Deriving the instance key

The reason a scan needs no cooperation from the contract's authors: the instance entry's ledger key depends only on the contract id. 

import { instanceLedgerKey, ledgerKeyToBase64 } from "./packages/sdk/src/footprint.ts";

const key = instanceLedgerKey("CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC");
const entries = await server.getLedgerEntries(key);
entries.entries[0]?.liveUntilLedgerSeq; // ledger number, not a timestamp

Add a watch from code

import { Keypair } from "@stellar/stellar-sdk";
import { addWatch } from "./packages/sdk/src/registry.ts";

const keypair = Keypair.fromSecret(process.env.SENTINEL_SECRET!);
await addWatch(server, cfg, {
  registryId: "CC4TQFW5GLQT...",
  owner: keypair.publicKey(),
  target: "CDLZFC3SYJYD...",
  label: "Payroll streams v2",
  warnLedgers: 518_400,
  keypair,
});

SENTINEL_SECRET is read from the environment and never written anywhere. Pass --secret only for a throwaway key.

Data shape

scan --json emits a ScanResult: network, rpcUrl, latestLedger, scannedAt, contracts[] (each with risk, ledger and second counts, ISO expiry, per-entry readings and an explorer URL) and a summary keyed by risk. The full example lives in the CLI reference.

Testing your change

npm test                                  # all SDK tests
node --test packages/sdk/test/ttl.test.ts # one file
npm run typecheck                         # whole repo

Tests never touch the network: the RPC layer is thin and everything worth asserting is pure. If a test needs a ledger number, pass it in.
