Know before your Soroban contract goes dark.

Soroban storage expires. When a contract's instance entry is archived it stops accepting calls, and the funds inside it are frozen until somebody pays to restore the footprint. Sentinel watches that deadline and tells you weeks ahead.

Read the CLI docs View the registry on testnet

A failure mode unique to Soroban

Entries on most chains live forever, so nobody needs this tool. On Stellar, every ledger entry carries a liveUntilLedgerSeq. A quiet month is enough to archive a contract's instance, and there is no event, no warning and no read that says "you have six days left" unless something asks.

Restoration is permissionless, so the fix is cheap. The hard part is knowing that it is needed — which is exactly what Sentinel does.

What it is

Registry contract

A public watchlist on Soroban. Anyone can register a contract; only its owner can remove it. No admin, no fees, no funds to steal.

Keeper CLI

Reads liveUntilLedgerSeq for every watched contract, converts ledgers to a wall-clock deadline, and classifies the risk.

CI gate

sentinel verify exits 2 when a contract is critical or archived, so a daily job becomes a deadline reminder.

Risk states

OK WATCH URGENT CRITICAL ARCHIVED
StateMeaning
OKMore than a warn window of ledgers remaining
WATCHInside the warn window — schedule an extension
URGENTA third of the window left
CRITICALA tenth of the window left — act now
ARCHIVEDNot live on this network: archived, or never deployed

Readings are capped by the network's maxEntryTtl (~7 days on testnet). That is why a freshly written contract can still read URGENT against a 30-day window: it is the cap, not a problem.

Quick start

git clone https://github.com/Streams-Hq/soroban-sentinel.git
cd soroban-sentinel
npm install

# any contract, no configuration
node packages/cli/src/index.ts scan --contract CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC

# the on-chain watchlist
node packages/cli/src/index.ts registry list

Design promises

  • Fundless contract. The registry never touches a token, so there is nothing to drain.
  • No admin. No upgrade authority, no pause switch, no privileged address.
  • No cooperation needed. The instance key is derivable from the contract id, so any contract can be watched.
  • Honest forecasts. 5 second ledger target, labelled as an estimate, and never optimistic about a lapsed entry.
